### Frontend
- Register = React Form to sign up user 
- Login = React Form to sign in the user 
- Model = Model class Representing User
### Backend
- TokenService = Generating and saving Token in database
- UserService = Manage Users & Roles
- AuthController = Authentification of User and naviagtion to admin or user panel
- UserController = Admin Panel Option where Admin can manage USer Roles and Groups
### Database
- User = Represents a User in the Database
- Jwt = Represents all kinds of token for Authenification
